# HR Employee Attrition Analysis

## Project Overview

This project analyzes employee data using Python to identify factors associated with employee attrition. Using the IBM HR Analytics Employee Attrition & Performance dataset, the analysis explores how employee demographics, job roles, departments, overtime, and other workplace factors relate to employees leaving an organization.

## Dataset

* **Source:** IBM HR Analytics Employee Attrition & Performance
* **Records:** 1,470 employees
* **Original Features:** 35 columns
* **Target Variable:** Attrition (Yes/No)

## Tools & Technologies

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* SciPy
* Jupyter Notebook

## Project Workflow

### 1. Data Cleaning

Inspected the dataset, checked missing values and duplicate records, and prepared relevant columns for analysis.

### 2. Exploratory Data Analysis (EDA)

Analyzed employee attrition across departments, job roles, business travel, education fields, marital status, and overtime. Explored numerical variables to understand employee characteristics and workplace patterns.

### 3. Statistical Analysis

* **Chi-Square Test:** Examined associations between categorical variables and employee attrition.
* **ANOVA:** Compared numerical variables across attrition groups.
* **Correlation Analysis:** Investigated relationships among numerical features.

### 4. Key Areas of Analysis

* Employee attrition patterns
* Department and job-role analysis
* Overtime and attrition
* Employee demographics and job characteristics
* Relationships between numerical variables
* Statistical significance of potential attrition factors

## Key Learnings

This project strengthened practical skills in data cleaning, exploratory data analysis, data visualization, hypothesis testing, and statistical interpretation. It also demonstrated how data analytics can help HR teams investigate employee turnover patterns.

## Conclusion

The project provides a structured analysis of employee attrition using Python and statistical methods. The findings help identify variables associated with employees leaving and provide a foundation for future employee retention strategies and predictive modeling.
